Layout

Geometry only — measure, spacing, rhythm, grids, radius and stacking order, and not one colour or border. Measure follows column count, not page identity: a three-up grid is a three-column shape wherever it lives. There are three breakpoints, and adding a fourth is a human decision.

Notification

Order of precedence

Read them in the order a page is actually built: layout puts things in place, typography decides what the text in them is, components gives them a surface, interaction decides how they respond, and notification is what happens after. A later layer may consume an earlier one's tokens. It may never redefine them.

When two grammars disagree, neither wins. A conflict means the rule was written into the wrong layer — move it, rather than adding an override.

Where to start

Five common tasks and the order to read in. Nobody needs all five pages at once.

Building a new page from nothing

Adding one section to a page that exists

04 layout only — pick a section class and a grid, and reuse whatever the neighbouring sections already use.

A control that does work when clicked

01 components for the action-state machine, then 05 notification for what it says when it finishes. Static .btn and stateful .act are not substitutes for each other.

Something is moving and it feels wrong

03 interaction — check it against the nine families and the timing table. One motion idea per section; two competing ones read as a bug.

Reviewing an existing page for drift

02 typography and 04 layout both end in an audit block. Grep the file, compare against the scale, and report counts before changing anything.

08

Before it ships

The six checks that catch nearly everything. Each page carries its own longer list; this is the shared floor.

  1. Exactly one .display on the page, at the top, and one .btn-accent per view.
  2. Zero raw font-size, max-width, padding or z-index values in the page file — tokens only.
  3. Every clamp that sets a font-size carries a rem term in its preferred value.
  4. Nested radii step down from their parent; a child never repeats it.
  5. One motion idea per section, and a reduced-motion block that mirrors every animation.
  6. Checked at 320, 768, 1440 and at 200% browser zoom, with no horizontal scrollbar.

Accent is scarce. If the orange is doing decoration rather than carrying a single point of meaning, take it out before anything else.
