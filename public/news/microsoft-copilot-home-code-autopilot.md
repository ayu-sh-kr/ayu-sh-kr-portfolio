# Microsoft Copilot adds Code and Autopilot to turn work requests into finished tasks

You ask Copilot to prepare a project update. It can draft the document, but what about the tracker your team needs afterward—or the follow-ups next week? Microsoft’s answer is a new Copilot built around **Home, Code, and Autopilot**, moving from a single chat toward work that can continue across tools and time.

## One starting point, three kinds of work

**Home** brings quick Chat requests and longer Cowork tasks into the same place, with Word, Excel, and PowerPoint documents editable inside Copilot. A coming **Today** view would pull together mail, meetings, Teams, and tasks, showing drafts and proposed schedule changes you can review. Microsoft says Today enters private preview in October.

**Code** is aimed at people who need a small app, dashboard, tracker, or automation without starting a software project. Describe what you need, and Copilot builds it using technology underlying GitHub Copilot. Microsoft says the code runs in a sandbox, with a **Managed Runtime** in preview for apps hosted inside the organization’s Microsoft 365 environment. Developers can still use GitHub Copilot for their regular coding work.

**Autopilot** goes further: give an agent a role, goal, and boundaries, and it can watch channels, follow up on threads, and resume recurring work without a fresh prompt. Microsoft says it gets its own identity and workspace inside the tenant, with permissions and audit controls. That is a product claim for a preview, so the useful question will be how clearly teams can inspect what it did and stop or correct it.

## When can people try it?

Microsoft says **Home and Code will begin rolling out through its Frontier program in the coming weeks**; Autopilot is expanding to **private preview at the end of September**. These are staged previews, not a launch for every Copilot user. Longer-running Cowork, Code, and Autopilot work uses usage-based billing, according to Microsoft, so teams will also need to watch cost as they delegate more.

The new Copilot pitch is simple: ask a question, build a tool, or leave a bounded task running from one place. The real test is whether a finished result arrives with enough context, control, and cost visibility to trust it.
