# Claude Opus 5.5 gets cheaper as Claude Code adds cloud-session credits

The latest AI-model race has a welcome twist: a stronger model that costs less to use. Anthropic released **Claude Opus 5.5** on September 22, saying it performs around the level of its more advanced Fable 5.1 on most work while costing **about 40% less** to run than Opus 5 on typical workloads. A day later, it announced a one-time credit for existing Claude Pro and Max subscribers to try Claude Code cloud sessions.

For developers, the news is less about a benchmark trophy and more about what a finished task costs.

## What changed with Opus 5.5?

Anthropic prices Opus 5.5 at **$4 per million input tokens and $20 per million output tokens**, compared with $5 and $25 for Opus 5. Cached input—the context a coding agent can reuse instead of processing from scratch—costs $0.20 per million tokens, **60% less** than before. Anthropic also says the model responds more than 30% faster and uses fewer tokens on typical work.

A 20% cut in the headline token price does not automatically mean every bill drops 40%. Anthropic's larger estimate combines lower prices with its reported efficiency gains, and your savings will depend on the task and how much context gets cached. Fast mode is available too, but it trades a higher price for speed.

This is the useful side of competition between AI labs. If a coding agent can finish a refactor in fewer steps and at lower cost, a team can afford to use it on **ordinary work**—not just an occasional impressive demo. That customer benefit is the story behind the model numbers.

## Claude Code can make motion through code

The [clip shared by @twoclipping](https://x.com/twoclipping/status/2103273003555402193) points to another kind of AI-assisted creation: producing a video-like animation by writing the code that draws and moves it. Think of a webpage or rendering program controlling shapes, text, camera movement and timing, then exporting the result as a clip.

This is **code-rendered animation**, different from a video model generating pixels directly from a prompt. The code-first route gives a creator editable timing, repeatable scenes and assets that may also work on a website. It still takes review and iteration; the clip is an example of a workflow, not an announcement that Opus 5.5 itself is a video-generation model.

## Claim the Claude Code cloud-session credit

[Anthropic announced](https://x.com/ClaudeDevs/status/2102871550974427462) a **one-time $100 cloud-session credit for existing Pro subscribers and $250 for existing Max subscribers**. Cloud sessions keep Claude Code working on Anthropic's infrastructure after you close your laptop.

To claim it, follow [Anthropic's offer link](https://x.com/ClaudeDevs/status/2102871555244257518) or run `/claim-credit` in Claude Code **by October 7, 2026**. Connect GitHub to start a session. The credit applies to **cloud sessions only**; those sessions use it first, then fall back to normal plan usage when it runs out.

A cheaper Opus model and credit to try cloud coding make the week's point clear: the AI race is starting to lower the cost of getting real work done.
